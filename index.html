A wave-based alternative to the Kronecker byte codec — Problem #4, ERA V5 Session 7

1. The Core Idea: Bytes as Waves

Kronecker: κ(b) = (1/√L) · vec( Σ one_hot(byte_p) ⊗ one_hot(position_p) ) → sparse, D=8192, ceiling at 32

Fourier:   φ(b) = (1/√L) · Σ wave(byte_p, position_p) → dense, D=512, configurable buffer bound
